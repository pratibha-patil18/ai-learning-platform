# AI Learning & Competency Assessment Platform

A web-based learning platform designed to assess a user's skills through interactive quizzes and identify areas where further learning is needed.

## Features

- Skill-based quiz assessment
- Interactive question and answer flow
- Performance/result evaluation
- Competency-gap identification
- Learning recommendations based on performance
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Structure and content of the application
- `style.css` — Styling, layout, animations and visual design
- `script.js` — Interactive functionality and quiz logic

## Project Background

This project was developed as part of a college hackathon focused on building an AI-assisted learning platform.

## Current Limitations

- The current version displays the assessment result but does not provide a review of the correct answers after completing the quiz.

## Future Improvements

- Add correct-answer review after quiz completion
- Backend integration for storing user progress
- User authentication
- Database integration
- More personalized learning recommendations
- AI-powered question generation and analysis
